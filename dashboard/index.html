  • P0Data contract + khung Cloud Run + pipeline deploy (đang chạy).
  • P1Lớp chất lượng dữ liệu — chỉ số completeness / validity / integrity, ngưỡng Đỏ/Vàng/Xanh.
  • P2Lớp phân tích — MoM/YoY, trung bình trượt, Pareto NCC + HHI, phát hiện bất thường, ngoại lệ đối soát theo tiền.

  • P4Hoàn thiện — tài liệu, rollback, chốt bản.
